# 🌌 Nexus Zen Aura

**Nexus Zen Aura** is an all-in-one holistic wellness, cognitive training, fitness, strategy gaming, and AI-powered English fluency web platform built to run seamlessly as a single-page application.

---

## ✨ Core Modules

1. **🎧 Mind Relax & Binaural Synthesizer**
   - Real-time **Web Audio API** stereo binaural beats generator (`432 Hz`, `528 Hz`, `10 Hz Alpha`, `4 Hz Delta`, `40 Hz Gamma`)
   - Ambient synth pads, procedural pink-noise rain mixer, and live HTML5 Canvas audio waveform visualizer
   - Guided **4-7-8** & **Box Breathing** visual orb and Tibetan singing-bowl meditation timer

2. **🧠 Brain Training Lab**
   - **Memory Matrix**: Progressive spatial grid recall challenge
   - **Speed Math Sprint**: 60-second arithmetic speed drill with combo multipliers
   - **Stroop Color Reflex**: Cognitive interference and reaction-speed test

3. **⚡ Kinetic Body Workout Studio**
   - Real-time **HTML5 Canvas biomechanical exercise animations** across 10 movements (*Jumping Jacks, Push-Ups, Jump Squats, Plank, High Knees, Lunges, Mountain Climbers, Burpees, Bicycle Crunches, Cobra Stretch*)
   - Difficulty scaling (**Beginner / Pro / Beast Mode**), HIIT interval timer, voice cues, and calorie tracking

4. **🕹️ Strategy & Arcade Zone**
   - **9×9 Sudoku**: Full puzzle generator with pencil notes, hints, and mistake tracking
   - **2048 Cyber Merge**: Keyboard, swipe, and D-pad support
   - **Minimax AI Tic-Tac-Toe**: Unbeatable AI opponent

5. **🎙️ AI English Fluency & Speaking Studio (A1 Beginner → C2 Pro)**
   - **4-Tier Level Progression**: Beginner (`A1–A2`), Intermediate (`B1–B2`), Advanced (`C1`), and Pro Native (`C2`)
   - **AI Voice Tutor**: Interactive roleplay and real-time grammar/fluency feedback powered by Gemini API + Web Speech API
   - **Dynamic Practice Generator**: Random sentences, phonetic tongue twisters, power vocabulary with IPA & Hindi hints, and pronunciation accuracy scoring
